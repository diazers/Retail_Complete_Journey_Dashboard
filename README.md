# Retail Complete Journey Dashboard

Power BI dashboard (PBIP project format) built on the Dunnhumby "The Complete Journey" retail dataset, covering revenue, RFM segmentation, campaigns, AOV and in-store display analysis.

## Repository layout
- `*.pbip`, `*.Report/`, `*.SemanticModel/`: the Power BI project (open the `.pbip` in Power BI Desktop)
- `Assets/`: report background images

dataset are from dunhumby a complete journey dataset

Data is imported from BigQuery and is not stored in this repo.
